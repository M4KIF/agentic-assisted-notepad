# Nervous-system overload analysis

When overload is part of a daily note or emotionally difficult exchange, use [`emotional-analysis`](../emotional-analysis/SKILL.md) alongside this assessment. That skill captures the user's felt experience and provides a precise, non-sentimental response; this skill owns capacity assessment and grounding. Use [`actionable-support`](../actionable-support/SKILL.md) when a concrete, immediately usable pause or recovery aid is warranted. In a daily bundle, contribute findings to `agentic/personal.md`; [`daily-note-analysis`](../daily-note-analysis/SKILL.md) coordinates file ownership.

## Description & Goal
Organize the user's self-reported capacity and overload cues to decide whether to continue analysis, pause, or simplify the next step. This is not a measurement of allostatic load, vagal function, or a clinical state. Body sensations and language can inform a tentative formulation, but do not establish a specific autonomic mechanism.

## Assessment Matrix

| Possible signal (not diagnostic) | User reports more capacity | User reports reduced capacity |
| :--- | :--- | :--- |
| **Head state** | Clearer thinking or flexibility, if reported | “Hot anvil,” cognitive flooding, or decision difficulty, if reported |
| **Body** | User says their body feels settled or available | Stomach clenching, tension, numbness, or other sensations named by the user |
| **Processing** | User can consider options and communicate preferences | User says they cannot take in more information, decide, or continue |
| **Behavior** | No inference from behavior alone | Withdrawal or urgency may be relevant context, but does not prove overload |

## Analytical Directive
1. Start with the user's explicit description. Ask one focused capacity question only if it would change the next step.
2. Offer a 1–10 self-rating only when useful; do not assign a number from prose or treat the scale as an objective measurement.
3. If the user self-rates at 7/10 or above, says they cannot process further, or describes comparable acute distress, use that as a pragmatic pause condition—not a validated clinical cutoff. Defer complex theorizing and consequential decisions; offer a choice of one simple grounding or pause action. Do not insist on a particular breathing technique or presume that grounding is welcome.

## Reassessment and evidence boundaries

Record a before/after self-rating only if the user volunteered or agreed to one. Otherwise describe the reported change in ordinary language or mark it unknown. Label body cues as reports; do not convert them into a medical diagnosis or a definitive autonomic mechanism.

During acute distress, defer blame allocation and irreversible relationship decisions as well as theory. If a pause is chosen, make it bounded with a mutually workable return time when another person is involved. If severe, new, or medically concerning physical symptoms are present, recommend appropriate professional or emergency evaluation rather than attributing them solely to stress.
